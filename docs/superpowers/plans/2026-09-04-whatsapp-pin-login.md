# WhatsApp OTP → Name + PIN Login Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First-time WhatsApp-OTP signup collects a name + mandatory 4-digit PIN so returning visitors can skip the OTP round-trip; a phone number already tied to a different (Google/email) account is detected and blocked *before* any OTP is sent, so no more silent duplicate accounts.

**Architecture:** One new DB column (`profiles.has_pin`) + one new rate-limited public edge function (`check-phone-login-method`) that tells the client which of three paths to take (send OTP / show PIN field / already linked elsewhere) before any session exists. PIN sign-in uses Supabase's native `signInWithPassword`/`updateUser({password})` against the *same* phone identity — no new auth identity type. Both `login.html` and `assets/signin-popup.js` call the same shared helpers in `assets/profile-seed.js`.

**Tech Stack:** Deno edge functions (Supabase), vanilla JS + Supabase JS SDK v2 (no framework), Postgres/PostgREST, Playwright (regression tests).

**Spec:** `docs/superpowers/specs/2026-09-04-whatsapp-pin-login-design.md`

## Global Constraints

- PIN is exactly 4 digits, numeric, mandatory on first setup (no skip).
- `check-phone-login-method` never reveals anything beyond one of three status strings — no name, email, or user id in the response, under any circumstance.
- Phone numbers are always normalized to bare 10 digits for storage/display; `+91` is only ever added at the point of calling `supabase.auth` (which requires E.164) or an external API — never stored that way anywhere else.
- Every new/changed edge function follows this project's existing admin-auth-free public-function pattern: CORS headers, `OPTIONS` short-circuit, `POST`-only, `{ error: "..." }` on failure. Deploy with `verify_jwt: false` (matches every other public function in this project, e.g. `get-site-settings`, `check-delivery-estimate`).
- Per this project's standing workflow rule: sync latest code first, and after this plan is fully implemented and verified, commit + push to GitHub AND deploy every changed edge function/migration to Supabase — do not leave changes undeployed.

```js
// ── Phone helpers — the one place these live. login.html and
// assets/signin-popup.js both import these instead of keeping their own
// duplicate copies (previously duplicated in both files).
export const phoneOk = (v) => {
  const digits = String(v || "").replace(/\D/g, "");
  if (digits.length === 12 && digits.startsWith("91")) return /^[6-9]\d{9}$/.test(digits.slice(2));
  return /^[6-9]\d{9}$/.test(digits);
};

export const normalizePhone10 = (raw) => {
  let d = String(raw || "").replace(/\D/g, "");
  if (d.startsWith("91") && d.length === 12) d = d.slice(2);
  if (d.startsWith("0") && d.length === 11) d = d.slice(1);
  return d;
};

export const toE164 = (phone10) => "+91" + phone10;

const CHECK_PHONE_LOGIN_METHOD_URL =
  "https://mgmgkwoxirvzdnmayhwq.supabase.co/functions/v1/check-phone-login-method";

// Asks check-phone-login-method which sign-in path to show for this phone
// number. Returns "error" (never throws) on any network/response problem,
// so callers can fail safe — falling back to the normal OTP flow — rather
// than getting stuck with no way forward.
export async function checkPhoneLoginMethod(phone10) {
  try {
    const res = await fetch(CHECK_PHONE_LOGIN_METHOD_URL, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ phone: phone10 }),
    });
    const data = await res.json().catch(() => null);
    if (!res.ok || !data?.status) return "error";
    if (data.status === "otp" || data.status === "pin" || data.status === "linked_elsewhere") {
      return data.status;
    }
    return "error";
  } catch (_) {
    return "error";
  }
}

// Signs in to an existing PIN account. The account's phone identity already
// exists in auth.users — this just supplies the password credential
// attached to it (see saveNameAndPin below).
export async function signInWithPin(phone10, pin) {
  const { error } = await supabase.auth.signInWithPassword({
    phone: toE164(phone10),
    password: pin,
  });
  if (error) return { ok: false, message: error.message };
  return { ok: true };
}

// Completes first-time (or reset) PIN setup for the CURRENTLY authenticated
// session — call only right after a successful OTP verify, while that
// session is still active. Saves the name, marks has_pin true, then
// attaches the PIN as this same phone identity's password — no new auth
// identity is created, it's the exact account that just verified via OTP.
export async function saveNameAndPin({ userId, name, pin }) {
  const { error: profileErr } = await supabase.from("profiles").upsert({
    user_id: userId,
    full_name: name,
    has_pin: true,
  });
  if (profileErr) return { ok: false, message: profileErr.message };

  const { error: pwErr } = await supabase.auth.updateUser({ password: pin });
  if (pwErr) return { ok: false, message: pwErr.message };

  return { ok: true };
}
```

Create `supabase/functions/check-phone-login-method/index.ts` (this is the local mirror path used throughout this project for edge functions — deployed via the `deploy_edge_function` MCP tool, not git):

```ts
// supabase/functions/check-phone-login-method/index.ts
//
// Public, unauthenticated — must run BEFORE any session exists, so it
// can't require a bearer token. Given a bare 10-digit phone number, tells
// the caller which sign-in path to show, without ever revealing whose
// account it is. See docs/superpowers/specs/2026-09-04-whatsapp-pin-login-design.md.
//
// Response is always exactly one of:
//   { status: "otp" }              — send a WhatsApp OTP as normal (brand
//                                     new number, OR an existing phone
//                                     account that hasn't set a PIN yet)
//   { status: "pin" }              — this account has a PIN set, show the
//                                     PIN field instead of sending an OTP
//   { status: "linked_elsewhere" } — this number is saved as contact info
//                                     on a different, non-phone-auth
//                                     account (e.g. Google) — do NOT send
//                                     an OTP; no phantom account is ever
//                                     created for this case
//
// Called as: POST { phone: "9876543210" }

import { createClient } from "https://esm.sh/@supabase/supabase-js@2.49.1";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "content-type",
  "Access-Control-Allow-Methods": "POST, OPTIONS",
};

const PHONE_RE = /^[6-9]\d{9}$/;

function jsonResponse(body: unknown, status = 200) {
  return new Response(JSON.stringify(body), {
    status,
    headers: { "Content-Type": "application/json", ...corsHeaders },
  });
}

function getEnv(name: string): string {
  const v = Deno.env.get(name);
  if (!v) throw new Error(`Missing env var: ${name}`);
  return v;
}

function envInt(name: string, fallback: number): number {
  const raw = Deno.env.get(name);
  const n = raw ? parseInt(raw, 10) : NaN;
  return Number.isFinite(n) && n > 0 ? n : fallback;
}

// Same abuse-policy shape as send-whatsapp-otp-hook, independent counters
// and independent log table — this endpoint is a plausible target for
// phone-number enumeration ("is this number registered?") otherwise.
const MAX_PER_PHONE_10MIN = envInt("LOGIN_CHECK_MAX_PER_PHONE_10MIN", 10);
const MAX_GLOBAL_PER_HOUR = envInt("LOGIN_CHECK_MAX_GLOBAL_PER_HOUR", 600);

Deno.serve(async (req: Request) => {
  if (req.method === "OPTIONS") return new Response("ok", { headers: corsHeaders });
  if (req.method !== "POST") return jsonResponse({ error: "Use POST" }, 405);

  try {
    const body = await req.json().catch(() => null);
    const phone10 = String(body?.phone || "").replace(/\D/g, "");

    if (!PHONE_RE.test(phone10)) {
      return jsonResponse({ error: "Enter a valid 10-digit Indian mobile number." }, 400);
    }

    const SUPABASE_URL = getEnv("SUPABASE_URL");
    const SUPABASE_SERVICE_ROLE_KEY = getEnv("SUPABASE_SERVICE_ROLE_KEY");
    const admin = createClient(SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, {
      auth: { persistSession: false },
    });

    // ── Abuse policy ────────────────────────────────────────────────────
    const now = Date.now();
    const tenMinAgo = new Date(now - 10 * 60 * 1000).toISOString();
    const hourAgo = new Date(now - 60 * 60 * 1000).toISOString();

    async function logAttempt(blocked: boolean, reason: string | null) {
      try {
        await admin.from("phone_login_check_log").insert({
          phone_e164: phone10,
          blocked,
          block_reason: reason,
        });
      } catch (e) {
        console.error("phone_login_check_log insert failed (non-fatal):", e);
      }
    }

    try {
      const [perPhone10Min, globalHour] = await Promise.all([
        admin.from("phone_login_check_log").select("id", { count: "exact", head: true })
          .eq("phone_e164", phone10).eq("blocked", false).gte("attempted_at", tenMinAgo),
        admin.from("phone_login_check_log").select("id", { count: "exact", head: true })
          .eq("blocked", false).gte("attempted_at", hourAgo),
      ]);

      if ((perPhone10Min.count ?? 0) >= MAX_PER_PHONE_10MIN) {
        await logAttempt(true, "per_phone_10min");
        return jsonResponse({ error: "Too many attempts. Please wait a few minutes and try again." }, 429);
      }
      if ((globalHour.count ?? 0) >= MAX_GLOBAL_PER_HOUR) {
        await logAttempt(true, "global_hour");
        return jsonResponse({ error: "Please try again shortly." }, 429);
      }
    } catch (e) {
      // Fail open — a broken rate limiter must never block a real sign-in.
      console.error("Abuse-policy check failed (failing open):", e);
    }

    await logAttempt(false, null);

    // ── The actual lookup ──────────────────────────────────────────────
    const { data: profileRow, error: profileErr } = await admin
      .from("profiles")
      .select("user_id, has_pin")
      .eq("phone", phone10)
      .maybeSingle();

    if (profileErr) {
      console.error("check-phone-login-method: profile lookup failed:", profileErr.message);
      return jsonResponse({ error: "Server error" }, 500);
    }

    if (!profileRow) {
      return jsonResponse({ status: "otp" });
    }

    const { data: authUserResp, error: authErr } = await admin.auth.admin.getUserById(profileRow.user_id);
    if (authErr || !authUserResp?.user) {
      console.error("check-phone-login-method: auth user lookup failed:", authErr?.message);
      return jsonResponse({ error: "Server error" }, 500);
    }

    const authPhone10 = String(authUserResp.user.phone || "").replace(/\D/g, "").slice(-10);
    const canLoginByThisPhone = authPhone10 === phone10;

    if (!canLoginByThisPhone) {
      return jsonResponse({ status: "linked_elsewhere" });
    }

    return jsonResponse({ status: profileRow.has_pin ? "pin" : "otp" });
  } catch (e) {
    console.error("check-phone-login-method error:", e);
    return jsonResponse({ error: "Server error", details: String((e as any)?.message || e) }, 500);
  }
});
```

```js
    startCooldown(resendBtn);
  });

  changeBtn.addEventListener("click", () => {
    if (cooldownTimer) clearInterval(cooldownTimer);
    currentPhone10 = null;
    needsPinSetup = false;
    status.textContent = "";
    hideAllSteps();
    phoneInput.value = "";
    phoneInput.focus();
  });

  verifyBtn.addEventListener("click", async () => {
    setCodeError("");
    const code = codeInput.value.trim();

    if (!/^\d{6}$/.test(code)) {
      setCodeError("Enter the 6-digit code we sent you.");
      return;
    }
    if (!currentPhone10) {
      status.textContent = "Please request a code first.";
      return;
    }

    verifyBtn.disabled = true;
    status.textContent = "Verifying…";

    const { error } = await supabase.auth.verifyOtp({
      phone: toE164(currentPhone10),
      token: code,
      type: "sms",
    });

    verifyBtn.disabled = false;

    if (error) {
      status.textContent = "Error: " + error.message;
      return;
    }

    // Same first-login profile seeding login.html does — shared helper so
    // the two never drift out of sync.
    try {
      const { data: sessData } = await supabase.auth.getSession();
      const session = sessData?.session;
      if (session?.user) {
        await upsertProfileIfPending(session.user.id);
        await ensureProfileFromPhone(session);
      }
    } catch (_) {
      // Never let profile seeding block the login itself.
    }

    if (!needsPinSetup) {
      status.textContent = "Logged in ✅";
      setTimeout(close, 700);
      return;
    }

    status.textContent = "";
    hideAllSteps();
    nameSetupStep.style.display = "block";
    setNameSetupError("");
    newPinInput.value = "";
    confirmPinInput.value = "";
    try {
      const { data: sess } = await supabase.auth.getSession();
      const uid = sess?.session?.user?.id;
      if (uid) {
        const { data: existing } = await supabase.from("profiles").select("full_name").eq("user_id", uid).maybeSingle();
        nameInput.value = existing?.full_name || "";
      }
    } catch (_) { /* non-fatal */ }
    nameInput.focus();
  });

  finishSetupBtn.addEventListener("click", async () => {
    setNameSetupError("");
    const name = nameInput.value.trim();
    const pin = newPinInput.value.trim();
    const confirmPin = confirmPinInput.value.trim();

    if (!name) {
      setNameSetupError("Enter your name.");
      return;
    }
    if (!/^\d{4}$/.test(pin)) {
      setNameSetupError("PIN must be exactly 4 digits.");
      return;
    }
    if (pin !== confirmPin) {
      setNameSetupError("PINs don't match.");
      return;
    }

    const { data: sess } = await supabase.auth.getSession();
    const uid = sess?.session?.user?.id;
    if (!uid) {
      setNameSetupError("Session expired — please refresh and log in again.");
      return;
    }

    finishSetupBtn.disabled = true;
    status.textContent = "Saving…";
    const result = await saveNameAndPin({ userId: uid, name, pin });
    finishSetupBtn.disabled = false;

    if (!result.ok) {
      setNameSetupError("Couldn't save: " + result.message + " — you're still logged in, try again.");
      return;
    }

    status.textContent = "All set ✅";
    setTimeout(close, 700);
  });
```

Note: the trailing `codeInput.addEventListener("keydown", (e) => { if (e.key === "Enter") verifyBtn.click(); });` and the `googleBtn.addEventListener(...)` block immediately after it are **unchanged** — leave them exactly as they are, directly following the code above.
